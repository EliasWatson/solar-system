# Solar System — live 3D

Interactive Three.js model of the solar system with every body placed where it is **right now** (or any date from 1600–2500 via the time controls).

Live: https://solar.eliasw.app

- 8 planets, dwarf planets (Pluto, Ceres, Eris, Haumea, Makemake, Sedna), notable asteroids (Vesta, Pallas, Juno, Hygiea, Psyche, Eros, Bennu, Apophis, Ryugu, Itokawa), Arrokoth, and 14 major moons.
- Planet positions: JPL *Approximate Positions of the Planets* Keplerian elements (valid 1800–2050). Small bodies: osculating elements from the JPL Small-Body Database (`npm run elements` refreshes `src/smallbodies.json`). The Moon uses simplified lunar elements; other moons use circular orbits with real periods (orbital phase approximate).
- Earth's rotation follows sidereal time, so day/night is correct (with city lights on the night side).
- Earth satellites: live CelesTrak GP elements propagated with SGP4 ([satellite.js](https://github.com/shashwatak/satellite-js)). ISS, Tiangong, Hubble, GOES-16, Landsat 9 and NOAA-20 are shown by default; groups (stations, Starlink, GPS, geostationary, weather, all active, …) load on demand from the sidebar and render as point clouds. Altitudes are exaggerated in enlarged mode.
- `functions/api/gp.js` is a Cloudflare Pages Function that proxies CelesTrak with a 2-hour edge cache (the client falls back to CelesTrak directly, which allows CORS).
- Enlarged-bodies or true-scale mode, orbit lines, labels, search (`/`), click/tap to fly to and follow a body, time rate slider, date picker.

## Develop
```
npm install
npm run dev
npm run build   # → dist/
```

## Deploy
Cloudflare Pages project `solar-system`: `npm run build && npx wrangler pages deploy dist  # run from repo root so functions/ is included; --project-name solar-system --branch main`
