# Solar System — live 3D

Interactive Three.js model of the solar system with every body placed where it is **right now** (or any date from 1600–2500 via the time controls).

Live: https://solar.eliasw.app

- 8 planets, dwarf planets (Pluto, Ceres, Eris, Haumea, Makemake, Sedna), notable asteroids (Vesta, Pallas, Juno, Hygiea, Psyche, Eros, Bennu, Apophis, Ryugu, Itokawa), Arrokoth, and 14 major moons.
- Planet positions: JPL *Approximate Positions of the Planets* Keplerian elements (valid 1800–2050). Small bodies: osculating elements from the JPL Small-Body Database (`npm run elements` refreshes `src/smallbodies.json`). The Moon uses simplified lunar elements; other moons use circular orbits with real periods (orbital phase approximate).
- Earth's rotation follows sidereal time, so day/night is correct (with city lights on the night side).
- Earth satellites: live CelesTrak GP elements propagated with SGP4 ([satellite.js](https://github.com/shashwatak/satellite-js)). ISS, Tiangong, Hubble, GOES-16, Landsat 9 and NOAA-20 are shown by default; groups (stations, Starlink, GPS, geostationary, weather, all active, …) load on demand from the sidebar and render as point clouds. Altitudes are exaggerated in enlarged mode.
- `functions/api/gp.js` is a Cloudflare Pages Function that proxies CelesTrak with a 2-hour edge cache (the client falls back to CelesTrak directly, which allows CORS).
- Enlarged-bodies or true-scale mode, orbit lines, labels, search (`/`), click/tap to fly to and follow a body, time rate slider, date picker.

## Other star systems
- 149 systems: every NASA Exoplanet Archive host within ~50 ly plus a curated list (TRAPPIST-1, Kepler-452/186/22/442, HD 209458, 51 Peg, 55 Cnc, HR 8799, TOI-700, LHS 1140, K2-18, …) and a hand-made Alpha Centauri A/B binary. Baked into `src/data/exoplanets.json` by `npm run exoplanets` (TAP query on `pscomppars`).
- ~9,700 background stars (naked-eye stars + everything within 16 pc) from the HYG v4.1 catalog (CC BY-SA 4.0) in `public/data/stars.json` (`npm run stars`). Stars are drawn at their real 3D positions with brightness computed from the camera position, so the sky changes as you travel.
- Each system gets its own local origin: the scene origin is moved to the destination star halfway through an interstellar flight (while the camera is light-years away), so planets stay precise; a logarithmic depth buffer covers the 10⁻⁷…10¹¹ unit range.
- Planet appearance is an artist's estimate from radius, mass and irradiation temperature (rocky / lava / water world / sub-Neptune / ice giant / gas giant / hot Jupiter). Orbital phase and orbit orientation are not known in general and are estimated deterministically. Missing radii/masses/periods are estimated from mass–radius and Kepler relations (marked "est.").
- Stars (including the Sun) use a type-aware procedural shader: quadratic limb darkening, animated granulation, starspots/faculae (G/K/M), flares on M dwarfs, smooth hot O/B/A photospheres with stronger glow, giants with few huge convection cells and a diffuse limb, tiny white dwarfs, and PSR B1257+12 as a neutron star with rotating beams. Class comes from spectral type, Teff, radius and log g; oblateness from v sin i when it exceeds 0.5%. Alpha Centauri A/B orbit their barycentre; Proxima is shown in place ~13,000 AU away.
- Habitable zone: approximate conservative limits (Kopparapu et al. 2013), drawn as a green ring.

## Develop
```
npm install
npm run dev
npm run build   # → dist/
```

## Deploy
Cloudflare Pages project `solar-system`: `npm run build && npx wrangler pages deploy dist  # run from repo root so functions/ is included; --project-name solar-system --branch main`
